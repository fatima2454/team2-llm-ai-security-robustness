Team 2: LLM and AI Security Robustness

CYB691 capstone project evaluating direct and indirect prompt injection attacks against locally hosted LLMs and RAG pipelines.

Project Overview

Our project focuses on testing the security robustness of locally hosted Large Language Models against prompt injection attacks. We plan to evaluate four direct prompt injection techniques and two indirect prompt injection techniques and compare how the models respond.

Current Scope

- Two locally hosted LLMs
- AWS EC2
- Ollama
- gpt-oss-20b
- Second model: TBD
- Four direct prompt injection techniques
- Two indirect prompt injection techniques
- Attack Success Rate and refusal rate analysis

Status

Initial planning and infrastructure setup.
